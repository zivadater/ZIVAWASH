# ZIVAWASH
ZivaWash is a modern multi-purpose cleaning product website designed for product presentation, batch tracking, and customer interaction. Built with clean HTML, CSS and JavaScript structure, optimized for branding, QR integration, and future database connection.
# پروژه Supabase + HTML + JS

## نحوه استفاده
1. لینک و ANON KEY Supabase خود را در `script.js` جایگزین کنید.
2. جدول `lottery_results` با ستون‌های `email` و `prize` بسازید.
3. کل فولدر را به ریپوی GitHub خود اضافه کنید و GitHub Pages را فعال کنید.
